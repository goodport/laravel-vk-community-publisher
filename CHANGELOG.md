# История изменений

Все заметные изменения пакета описываются в этом файле.

## Unreleased

- Добавлено описание структуры и правил пакета в `AGENTS.md`.

## 0.1.0 — 2026-11-05

- Первая версия пакета.
- Публикация постов на стену сообщества через `wall.post`.
- Публикация ссылок с превью: получение фото через `wall.parseAttachedLink`, проверка размера и передача `attachments` с `link_photo_id`.
- Контракт `CommunityPublisher` с методами `publish()` и `delete()`.
- Передача id сообщества и токена при каждом вызове через `CommunityCredentials`, без хранения в конфиге.
- HTTP-клиент VK API с настраиваемой версией, адресом и таймаутом, с маскировкой токена в логах.
- Повторы `wall.parseAttachedLink`, если ВК отвечает без фото.
- Подготовка JPEG-превью под карточку ссылки через `PreviewImageFactory`.
- Исключение `VkApiException` при ошибках ВК, отсутствии валидного превью и ответе без `post_id`.
- Публикуемый конфиг, singleton-биндинги и авторегистрация service provider.
- Тесты на Orchestra Testbench с HTTP-фейками, без обращений к реальному ВК.
